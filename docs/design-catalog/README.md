# Reccut catalog seed

22 original Reccut templates with matching PNG previews, published by the website workflow at https://sirbull.github.io/reccut/design-catalog/index.json. New profiles use this catalog automatically under Design → Templates → More Templates. Settings → Plugins → Design → Online Template Catalog lets users change or clear the address; existing saved choices are preserved.

The files are validated Reccut template-format version 1 documents. Image layers are reusable placeholders, not references to local project files. Previews use only original procedural shapes and text. New entries can be added to index.json without an app update. Preserve relative paths when adding entries or hosting a copy. See ../DESIGN-ONLINE-SETUP.md for setup and offline behavior.
