# Reccut catalog seed

22 original Reccut templates with matching PNG previews. Publish this directory to a public HTTPS/static host, preserving index.json and relative paths. Configure that index URL in Settings → Design → Online Template Catalog.

The files are validated Reccut template-format version 1 documents. Image layers are reusable placeholders, not references to local project files. Previews use only original procedural shapes and text. New entries can be added to index.json without an app update. See ../DESIGN-ONLINE-SETUP.md for publisher requirements. This catalog has not been published automatically.
